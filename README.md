## Project Overview
This project works with the Superstore Sales dataset, a single wide table of 9,800 order lines and 18 columns covering sales from January 2015 to December 2018. The raw data mixes customer, product, location, shipping, and date details in one table, which makes it hard to analyze and maintain. The project cleans the data, restructures it into a star schema (one fact table linked to dimension tables), and uses it to forecast future sales. The results will be presented through the final model and the sales forecast.

---

## Project Objectives
- Clean the raw dataset and fix data quality issues (missing values, inconsistent product names, data types, date formats)
- Design and build a star schema with a fact table and dimension tables
- Perform statistical analysis on sales data (descriptive statistics, distributions, and comparisons across segments, regions, and product categories)
- Aggregate sales over time and analyze yearly trends and seasonality
- Forecast future sales using a time series forecasting model

---

## Project Scope
- Dataset: Superstore Sales (9,800 rows, 18 columns, 2015–2018)
- Data cleaning and preparation
- Star schema design: `Fact_Sales` linked to `Dim_Customer`, `Dim_Product`, `Dim_Location`, `Dim_Ship_Mode`, and `Dim_Date`
- Statistical analysis of sales across customers, products, and regions
- Monthly sales analysis and trend/seasonality exploration
- Sales forecasting with confidence intervals
